# 知研 · Scholar Workbench

本地优先的科研文献工作台，为传智杯 AI 创新应用与 AI 大模型创新应用两赛道共用开发。

## 开发状态

正在从零实现，不能把本 README 视为已通过官方评测的声明。真实验收结果记录在 `docs/validation.md`；开发过程记录在 `docs/development-log.md`。

## 计划功能

- PDF 导入、OCR、结构化段落、版本与重复检测。
- 本地混合检索、问答与可点击原文依据。
- 双栏阅读、逐段翻译与原文定位。
- arXiv 检索、导入、研究兴趣追踪。
- 引用关系图、文献重要性指标与有引用的综述。
- 学术写作、CSV 图表与可导出的绘图代码。

## 环境

Python 3.11+、现代浏览器、Ollama（已配置本地模型时启用 AI 生成）。不带模型时，仍可使用解析、关键词检索和图谱；界面会提示生成能力未就绪。

后续启动、测试及参赛材料说明将随实际实现更新。
